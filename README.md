# FlowState AI

Мобильное приложение (Expo SDK 57 + React Native + TypeScript). ТЗ — `docs/SPEC.md`, правила для работы с ИИ — `CLAUDE.md`.

## Запуск (Windows)

1. Установи **Node.js LTS** (22 или новее) с nodejs.org.
2. Открой терминал в этой папке:
   ```bash
   npm install
   npx expo start
   ```
3. На iPhone установи **Expo Go** и отсканируй QR-код из терминала камерой.
   - Телефон и ПК в одной Wi‑Fi сети. Не подключается → `npx expo start --tunnel`.
   - В браузере: нажми `w`.

## Что работает

| Экран | Что умеет |
|---|---|
| Онбординг | Приветствие, 11 вопросов (имя, цель, опыт, дни, оборудование, время, ограничения, цикл, контрацепция), согласия GDPR |
| Today | Daily Alignment (сгенерировать / продолжить / итог), неделя, Cycle, Readiness, Progress, Sleep |
| Чек-ин | 6 шагов → движок → «Synthesising your plan…» |
| План | Рекомендация + «Why?», чипы факторов, упражнения, Customize (замена), «период начался?» |
| Тренировка | Сеты / повторы / кг, галочки, таймер отдыха, «Feels too heavy?» (−10 % веса, −2 повтора, +30 с отдыха, замена, спросить коуча), Finish → усилие 1–10 + «помогло?» |
| Упражнение | Техника по шагам, мышцы, лёгкие альтернативы (видео — позже) |
| Train («Sync Training») | Календарь недели, кольца Workouts / Volume / Minutes, карточка FlowState AI Plan, последние тренировки, программа, библиотека из 40 упражнений |
| Cycle | Кольцо фаз, день цикла, прогноз, календарь, отметка начала/конца месячных |
| Coach | Чат. Без бэкенда — встроенный офлайн-коуч по правилам; с Supabase — Claude |
| Профиль | Редактирование всего, экспорт данных, удаление всех данных, демо-история |

Данные хранятся на телефоне (AsyncStorage). Прогрессия весов работает по истории тренировок.

**Демо:** Профиль (кружок с буквой на Today) → «Load demo history» — заполнит 3 недели тренировок.

## Бэкенд: вход + база Neon + ИИ-коуч

Сервер лежит в папке `server/` (Hono + Better Auth + Neon Postgres, деплой на Vercel). Пошагово — `server/README.md`.

Кратко:
1. Neon → проект в регионе **Frankfurt** → скопировать pooled connection string.
2. `cd server` → `npm install` → заполнить `.env` → `npm run migrate` → `vercel`.
3. В корне приложения создать `.env` с `EXPO_PUBLIC_API_URL=https://<твой-сервер>.vercel.app` и перезапустить `start.bat`.

Пока `EXPO_PUBLIC_API_URL` пустой, приложение работает офлайн без входа (как раньше).
С сервером: экран входа (Email / Apple / Google), данные синхронизируются с Neon, коуч отвечает через Claude, «Delete my account» удаляет всё на сервере.

| Команда | Что делает |
|---|---|

| `npm test` | 21 тест движка рекомендаций |

| `npx expo install <пакет>` | добавить библиотеку |

## Структура

```
src/app/          экраны (Expo Router)
src/components/   UI-кит
src/engine/       движок рекомендаций + библиотека упражнений + тесты
src/state/        состояние (zustand, сохраняется на устройстве)
src/lib/          даты, форматирование, коуч
src/mocks/        демо-данные
server/           API для Vercel: вход, синхронизация с Neon, ИИ-коуч
docs/             ТЗ и макеты
```
